# Axodus organization profile

This repository is the versioned institutional representation of the local
Axodus workspace. The local workspace coordinates independent repositories and
is intentionally not a monorepo.

## Responsibilities

- publish the public organization profile from [`profile/README.md`](profile/README.md);
- present Axodus with clear, evidence-based institutional language;
- guide visitors toward the repositories owned by each ecosystem nucleus;
- maintain organization-level community and automation files when required;
- avoid presenting plans, prototypes, or documentation baselines as production systems.

Product code, contracts, services, applications, and domain documentation remain
in their respective repositories. The canonical public knowledge corpus is
maintained in [`Axodus/Documentation`](https://github.com/Axodus/Documentation).

## Communication standard

Organization-facing material should be written in clear English and should
distinguish implemented capabilities from prototypes, research, planned work,
and evidence-gated execution. Do not publish guaranteed-return language,
unsupported maturity claims, unverified partnerships, or implied production
authority.
